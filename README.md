# Live Weather Impact Dashboard

An interactive Power BI dashboard that turns raw weather data into a clear one-page view of current conditions, air quality and the 7-day outlook.

## Overview
The dashboard tracks weather for multiple locations (Goa, Hoskote and Kathmandu in this view) and shows how temperature, humidity, wind and air quality change across the forecast period. It converts raw data into an easy-to-read report for quick decisions.

## Key Features
- **Location cards:** Current temperature and conditions with quick comparison across locations
- **KPI cards:** Humidity, wind speed, visibility, pressure, UV index and precipitation
- **7-day forecast:** Daily weather icons plus a line chart showing the temperature trend
- **Sunrise and sunset:** Daily timings at a glance
- **Air Quality Index:** Gauge and colour-coded indicators for PM10, PM2.5, SO2, NO2, CO and O3
